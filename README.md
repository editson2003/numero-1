# Chen Chen — presentación CAD

Paquete editable de las 21 láminas A1 del proyecto de agua potable.

**[Descargar paquete CAD editable (.zip)](https://github.com/editson2003/numero-1/raw/refs/heads/main/CHEN_CHEN_CAD_EDITABLE.zip)**

El paquete incluye:

- DXF con la presentación modificada, rótulos y mapas vectoriales editables.
- DWG original sin cambios.
- Archivo LISP para aplicar los ajustes de presentación al DWG desde AutoCAD/Civil 3D para Windows.
- Instrucciones `LEEME_PRIMERO.txt` y fuentes de los mapas.

El DXF ya contiene las mejoras. Para conservar los objetos inteligentes de Civil 3D en el DWG, sigue las instrucciones del paquete y guarda una copia nueva desde AutoCAD. El LISP fue revisado estructuralmente, pero no se ejecutó dentro de AutoCAD en este entorno.
